# Gran Viaje Pareja Mayo 2027 - Comparador Sudeste Asiático

Sitio web interactivo y comparador de viaje para Indonesia, Malasia, Vietnam y Sri Lanka (15 - 28/29 Mayo 2027).

## Acceso Web
🌐 Puedes ver la web en directo en GitHub Pages:
https://ignaciocastellanoestrella-tech.github.io/websudesteasiatico/

## Contenido
- **Vuelos**: Salidas desde Madrid (MAD) y Málaga (AGP), comparativa vuelta Viernes 28 vs Sábado 29 con enlaces a Google Flights.
- **Itinerarios Día a Día**: Rutas detalladas con fotos y recomendaciones en los 4 destinos.
- **Hoteles**: 3 alternativas por escala (Calidad/Precio, Boutique Romántico, Lujo Asequible) con precios reales y enlaces directos a Booking.com.
- **Simulador de Presupuesto en Tiempo Real**: Cálculo interactivo de vuelos, hoteles, transportes con chófer, comidas, visados oficiales, actividades y seguro IATI.
